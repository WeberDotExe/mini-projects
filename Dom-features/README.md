# Advanced DOM Features

A collection of interactive UI experiments I built with vanilla JavaScript and GSAP to practice DOM manipulation, mouse events, and animations.

## Live Demo

uifeatures.vercel.app

## Technologies

* HTML5
* CSS3
* JavaScript
* GSAP

## About

This project is a small playground containing three different interactive features.

The first is a reactive rectangle that changes its colors based on the mouse cursor position. The second is an image-reveal effect for a list of Marvel characters. The third is an Instagram-style story viewer that displays images in a full-screen view for a limited time.

I used vanilla JavaScript for the interactions and GSAP for handling the animations and transitions.

## What I Learned

While building this project, I practiced:

* DOM manipulation and traversal
* Mouse events
* Tracking mouse coordinates
* Working with `mapRange()` in GSAP
* Creating hover interactions
* Building image-reveal effects
* Creating a temporary story viewer
* Integrating a third-party animation library

## Running Locally

Clone the repository:

```bash
git clone https://github.com/WeberDotExe/mini-projects.git
```

Go into the project folder:

```bash
cd mini-projects/Dom-features
```

Then open `index.html` in your browser.
