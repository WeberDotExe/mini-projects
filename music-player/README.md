# Spotify-Clone Music Player

A Spotify-inspired music player I built with vanilla JavaScript to practice working with audio playback, dynamic UI updates, and JavaScript data structures.

## Live Demo

musicplayer-iota.vercel.app

## Technologies

* HTML5
* CSS3
* JavaScript
* HTML5 Audio API

## About

This project is a simple music player with a playlist of songs. The song data is stored in an array of objects containing information such as the track title, artist, album artwork, and audio file.

The player allows users to play and pause songs and move between tracks. Whenever the current song changes, the interface updates with the corresponding album artwork, background image, song title, and artist.

## What I Learned

While building this project, I practiced:

* Working with the HTML5 Audio API
* Managing audio playback with JavaScript
* Using arrays of objects to store song data
* Dynamically updating the DOM
* Handling play, pause, and track navigation
* Keeping the UI in sync with the current audio state

## Running Locally

Clone the repository:

```bash
git clone https://github.com/WeberDotExe/mini-projects.git
```

Go into the project folder:

```bash
cd mini-projects/music-player
```

Then open `index.html` in your browser.

Make sure the audio files used by the project are present in their expected locations.
