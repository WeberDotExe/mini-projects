# Guess the Number

A simple number guessing game I built to practice JavaScript logic, state management, form handling, and DOM manipulation.

## Live Demo

[View Live Demo](#)

## Technologies

* HTML5
* CSS3
* JavaScript

## About

The game generates a random number between 1 and 100, and the player gets 10 attempts to guess it.

After each guess, the game gives feedback on whether the number is too high or too low. It keeps track of previous guesses and the number of attempts remaining, and once the game ends, the input is disabled until the player starts a new game.

## What I Learned

While building this project, I practiced:

* Generating random numbers with JavaScript
* Handling form input
* Managing game state
* Using arrays to store previous guesses
* Conditional logic
* Dynamically updating the DOM
* Disabling inputs after the game ends
* Resetting the game state
