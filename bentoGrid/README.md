# Bento Grid Layout

A responsive bento-style webpage I built to practice CSS Grid and learn how to create more complex layouts using native CSS.

## Live Demo

bentogirid.netlify.app

## Technologies

* HTML5
* CSS3
* CSS Grid

## About

The main focus of this project was experimenting with CSS Grid instead of relying on Flexbox or absolute positioning for the overall layout.

I used grid areas, columns, and rows to arrange different sections of the page into a bento-style design. The layout also adapts to different screen sizes while keeping the content organized.

## What I Learned

While building this project, I got more comfortable with:

* `grid-template-areas`
* `grid-template-columns`
* `grid-template-rows`
* Creating responsive layouts with CSS Grid
* Using semantic HTML5 elements
* Structuring multiple sections within a single grid layout

## Running Locally

Clone the repository:

```bash
git clone https://github.com/WeberDotExe/mini-projects.git
```

Go into the project folder:

```bash
cd mini-projects/bentoGrid
```

Then open `index.html` in your browser.
