## About This Repository

These are intentionally small projects. I built them to focus on specific concepts, experiment with different ideas, and get more comfortable building things without relying on tutorials.

Each project has its own README with more details about the implementation, technologies used, and what I learned while building it.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/WeberDotExe/mini-projects.git
```

Move into the repository:

```bash
cd mini-projects
```

For HTML/CSS/JavaScript projects, open the project's `index.html` file in your browser.

For React projects:

```bash
npm install
npm run dev
```
